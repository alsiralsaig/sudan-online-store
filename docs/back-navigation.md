# زر الرجوع في التلفون داخل تطبيقات سند

## المشكلة
كل شاشات تطبيق الجمهور (تبويب / متجر / تفاصيل إعلان / سلة / نوافذ) كانت **حالة React**
فقط. زر الرجوع في التلفون لا يجد صفحة في سجل الـWebView، فيظهر
«اضغط رجوع تاني للخروج» حتى والمستخدم داخل متجر بعيد.

## الحل (داخل الويب — يعمل في المتصفح وفي التطبيق)
`src/SanadClientApp/useAppHistory.ts`:
- كل انتقال يُسجَّل كخطوة في سجل التلفون عبر **`location.hash`**
  بصيغة `#s={"page":"store","id":"paradise","tab":"market_home"}`.
- سبب استخدام `hash` بدل `pushState`: تغيير الـhash يُنشئ خطوة تنقّل حقيقية
  يراها `WebView.canGoBack()` في **كل** إصدارات أندرويد (حتى الأغلفة القديمة).
- عند `hashchange`/`popstate` تُستعاد الشاشة السابقة كاملة:
  التبويب + المتجر المفتوح + تفاصيل الإعلان + وضع استعراض السوق وقسمه.
- الرجوع من أول شاشة (لا يوجد سجل) ⇒ الصفحة الرئيسية، ومنها يخرج التطبيق
  برسالة «اضغط رجوع تاني للخروج».

## الغلاف الأندرويدي
`native-wrapper/app/src/main/java/app/wrapper/MainActivity.java`:
```java
if (keyCode == KeyEvent.KEYCODE_BACK && web.canGoBack()) { web.goBack(); return true; }
```
`onBackPressed()` نفس المنطق: رجوع داخل الصفحة أولاً، والرسالة فقط في الجذر.

## ما تم توصيله بالسجل
- التبويبات السفلية (الرئيسية / المزادات / الرسائل / المزيد / السلة)
- فتح متجر من السوق، تفاصيل إعلان، استعراض الأقسام/المعارض/المتاجر
- نوافذ: الأقسام، البحث، إنشاء إعلان
- أزرار «رجوع» داخل الشاشات

## سلوك متوقع
| من | ضغط رجوع |
|---|---|
| داخل متجر | يرجع للسوق/الرئيسية |
| تفاصيل إعلان | يرجع للرئيسية |
| تبويب فرعي | يرجع للتبويب السابق |
| الصفحة الرئيسية | «اضغط رجوع تاني للخروج» ثم يخرج |
